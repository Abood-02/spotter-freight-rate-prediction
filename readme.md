# Spotter Freight Rate Prediction Pipeline

End-to-end Machine Learning pipeline for commercial freight rate prediction (`posted_rate`, in USD). Developed for the **Spotter Machine Learning Engineer** hiring assessment.

---

## 1. Project Overview & Architecture

The objective is to accurately predict transaction rates for truckload freight shipments given origin/destination coordinates, route distance, equipment type, weight, timestamps, and market indicators.

```
spotter/
├── src/
│   ├── __init__.py
│   ├── preprocessing.py    # DataPreprocessor: sign-flip rectification, robust imputation, GPS lookup
│   ├── features.py         # FeatureEngineer: 27 geospatial, calendar, tortuosity & baseline features
│   ├── split.py            # get_temporal_split: chronological out-of-time train/val split
│   └── models.py           # 3-tier modeling hierarchy (Heuristic, Ridge, LightGBM)
├── models/
│   └── production_pipeline.joblib  # Serialized full production pipeline bundle
├── scorer_results/
│   └── candidate_december.png      # Acceptance chart generated by score.py
├── eda.py                  # 6-stage forensic Exploratory Data Analysis script
├── train.py                # Benchmarking, model training, and artifact persistence script
├── predict.py              # Production inference script (generates submission CSVs)
├── score.py                # Spotter's official acceptance test and chart generator
├── requirements.txt        # Pinned project dependencies
└── .gitignore              # Ignores .venv, cache files, and local binaries
```

## 2. Quickstart & Reproduction Guide

### Prerequisites
* Python 3.10+ (tested on Python 3.14)
* PowerShell or Bash terminal

### Step 1: Environment Setup
Clone the repository and set up a dedicated virtual environment:

```bash
# Create virtual environment
python -m venv .venv

# Activate environment (Windows PowerShell)
.\.venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt
```

### Step 2: Run Forensic Exploratory Data Analysis
Executes the 6-stage data quality audit (detects negative weights, missingness, and correlation dynamics):

```bash
python eda.py
```

### Step 3: Train & Benchmark Models
Trains the 3-tier model hierarchy on the temporal holdout split, displays the performance leaderboard, retrains on 100% of labeled data, and serializes the production model bundle:

```bash
python train.py
```

### Step 4: Generate Submission Predictions
Generates `validation_predictions.csv` (12,000 holdout loads) and populates `december-chart-inputs.csv` (31 daily loads):

```bash
python predict.py
```

### Step 5: Execute Spotter's Official Acceptance Test
Validates both submission files against Spotter's integrity constraints and creates the December forecast chart:

```bash
python score.py --predictions validation_predictions.csv --december-predictions december-chart-inputs.csv
```

**Verification Output:**
```
Validated 12,000 final predictions.
Validated 31 fixed December predictions.
Created chart: scorer_results/candidate_december.png
Final validation metrics are calculated by Spotter after submission.
```

## 4. Key Engineering Insights

1. **Negative Weight Rectification:** Uncovered 292 rows in train and 145 rows in validation with negative weights (min: $-47,500$ lbs). Forensic audit confirmed a sign-inversion bug; fixed via `.abs()`.
2. **Rate-Per-Mile Dimensional Anchor:** `quote_signal` alone correlated at $r = -0.04$ with rate. Multiplying by distance (`quote_signal * distance`) revealed the true $r = 0.899$ commercial baseline.
3. **17.5% Unseen Lane Generalization:** 736 lanes in validation never appeared in training data. Generalization was achieved by engineering continuous Haversine geodesic distance, route tortuosity, and coordinate bounding boxes.
4. **Chronological Splitting:** Avoided random K-Fold data leakage by implementing a strict temporal split (Jan–Aug training vs Sep–Oct validation).
